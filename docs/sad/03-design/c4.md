# C4 — Hướng A

Sơ đồ Mermaid (C4 + sequence): [diagrams.md](diagrams.md). Khung màn: [wireframes/README.md](wireframes/README.md).

## Level 1 — Context

Người học (tài khoản thử), giáo viên/CMS, JPLearn Platform. Platform phụ thuộc Object Storage (media) và (tuỳ chọn) Transcode.

## Level 2 — Container

```
[Web Next.js] ──┐
[Expo iOS/iPad/Android] ──┼── HTTPS JSON ── [API FastAPI]
[CMS Web admin] ──┘                         │
                                            ├── PostgreSQL
                                            ├── Object Storage
                                            └── (Q1 optional) Transcode worker
```

- **Web:** learner shell + (cùng app hoặc `apps/cms`) staff CMS. v1 được phép CMS là route `/staff` bảo vệ role, không bắt buộc app tách.
- **Mobile:** một Expo app; iPad dùng layout `device_class=ipad`.
- **API:** auth, catalog, sessions, progress, flags, events, signed media URLs.
- **DB:** nguồn sự thật identity/catalog/progress.
- **Storage:** file gốc; API cấp playback URL.

Client **không** đọc DB, không nói chuyện thẳng với storage (trừ URL đã ký).

## Level 3 — Component API (Clean Architecture)

Backend FastAPI (`apps/api-python`) được tổ chức theo 4 tầng ranh giới nghiêm ngặt (ADR-006):

1. **Entrypoints (`entrypoints/http/`, `entrypoints/cli/`):**
   - FastAPI routers: `auth`, `catalog`, `sessions`, `flags`, `media`, `health`.
   - Middleware: `RequestIdMiddleware`, CORS, exception handlers.
   - Pydantic HTTP schemas nằm cùng HTTP routers; CLI gồm `migrate`, `seed`, `reconciliation`.
2. **Composition Root (`bootstrap.py`):**
   - `AppContainer` và các factory functions (`create_uow`, `create_*_repository`, `create_media_signer`).
3. **Application Layer (`application/`):**
   - Handlers (Use Cases): `identity`, `catalog`, `learning`, `flags`, `media`, `reconciliation`.
   - Ports (Protocols): `UserRepository`, `CatalogRepository`, `LearningRepository`, `FlagsRepository`, `MediaRepository`, `StoragePort`, `AsyncUnitOfWork`, `MediaUrlSigner`, `PasswordHasher`, `TokenService`.
   - Read Models / DTOs.
4. **Domain Layer (`domain/`):**
   - Pure Python aggregates & entities: `UserAccount`, `CatalogItem`, `LearningSession`, `LearnerProgress`, `MediaAsset`.
   - Pure Domain rules: `RangeParser`, `minutes_from_duration`, domain exceptions.
5. **Adapters Layer (`adapters/`):**
   - Persistence: SQLAlchemy repositories, `SqlAlchemyUnitOfWork`.
   - Storage: `LocalFilesystemStorage`.
   - Security: Argon2, PyJWT, `HmacMediaUrlSigner`.
   - Observability: background alert worker & queue.

Không có `GrammarModule`, `FlashcardModule`, `TranslationModule`.

Package root chỉ giữ `__init__.py`, `bootstrap.py`, `settings.py`. Environment
resolution thuộc `config/`; công cụ đối chiếu contract thuộc `tooling/`. Runtime
HTTP không import công cụ OpenAPI diff. Xem `apps/api-python/README.md` cho các
đường chạy ASGI/CLI hiện tại; đường import trong evidence lịch sử không đổi.

## Level 4
