# C4 — Hướng A

Sơ đồ Mermaid (C4 + sequence): [diagrams.md](diagrams.md). Khung màn: [wireframes/README.md](wireframes/README.md).

## Level 1 — Context

Người học (tài khoản thử), giáo viên/CMS, JPLearn Platform. Platform phụ thuộc Object Storage (media) và (tuỳ chọn) Transcode.

## Level 2 — Container

```
[Web Next.js] ──┐
[Expo iOS/iPad/Android] ──┼── HTTPS JSON ── [API FastAPI]
[CMS Web admin] ──┘                         │
                                            ├── PostgreSQL
                                            ├── Object Storage
                                            └── (Q1 optional) Transcode worker
```

- **Web:** learner shell + (cùng app hoặc `apps/cms`) staff CMS. v1 được phép CMS là route `/staff` bảo vệ role, không bắt buộc app tách.
- **Mobile:** một Expo app; iPad dùng layout `device_class=ipad`.
- **API:** auth, catalog, sessions, progress, flags, events, signed media URLs.
- **DB:** nguồn sự thật identity/catalog/progress.
- **Storage:** file gốc; API cấp playback URL.

Client **không** đọc DB, không nói chuyện thẳng với storage (trừ URL đã ký).

## Level 3 — Component API (logical)

- `AuthModule` — FR-ID-*
- `CatalogModule` — FR-CAT-*, FR-CMS-*
- `SessionModule` — FR-SES-*
- `ProgressModule` — FR-PRG-*
- `FlagsModule` — FR-FLG-*
- `EventsModule` — FR-EVT-*
- `MediaModule` — upload + playback URL

Không có `GrammarModule`, `FlashcardModule`, `TranslationModule`.

## Level 4

Không bắt buộc Q1. Code sau cổng SAD-3 bám module trên.
