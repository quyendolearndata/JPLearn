# Brief — Mặc áo khoác (level 0)

| Field | Giá trị |
|---|---|
| topic_id | `daily_home` |
| ci_level | 0 |
| visual_support | high |
| duration_seconds | ~80 |
| media_type | video |
| has_l1_translation | false |

## Tình huống (nội bộ)

Người lấy áo khoác từ móc treo, xỏ hai tay áo, cài từng nút, đứng ngắm trước gương. Camera thấy áo, tay và nút áo.

## Thoại (JP, ít, lặp)

- ジャケット、ジャケット
- きる、きる
- ボタン、ボタン

Không nói: 「きるの意味は“mặc”です」.

## Cấm

- Dạy từ vựng bằng cặp Việt–Nhật.
- Thêm `translation_vi` trên CMS.
